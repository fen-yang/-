# 项目核心功能优先级

本项目采用 MoSCoW 优先级划分方法（P0=必须有、P1=应该有、P2=可以有）。

## 优先级列表

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 活动发布 | P0 | 管理员可以发布活动信息 |
| 学生报名 | P0 | 学生可以在线报名 |
| 名单审核 | P1 | 管理员审核报名资格 |
| 二维码签到 | P0 | 扫码完成签到 |
| 统计导出 | P1 | 导出签到数据 |

## 优先级说明

- **P0（Must Have）**：系统核心功能，必须实现
- **P1（Should Have）**：重要功能，应尽量实现
- **P2（Could Have）**：可选功能，有时间再实现
